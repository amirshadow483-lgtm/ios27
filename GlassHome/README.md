# Glass Home — لانچر الهام‌گرفته از Liquid Glass برای POCO X3 GT (MIUI 14)

> این یک **لانچر اندرویدی مستقل** است که ظاهرش از زبان طراحی «Liquid Glass» اپل الهام گرفته است.
> **iOS واقعی نیست** و ربطی به Apple ندارد. فقط صفحه Home، App Library، Control Center و پنل اعلان‌ها را تغییر می‌دهد.

## ⚠️ وضعیت ساخت و تست (صادقانه)
- سورس پروژه کامل نوشته شده است، اما **APK در محیط من ساخته و روی گوشی تست نشده** (Android SDK/Gradle/شبکه در دسترس نبود).
- پروژه **حتی کامپایل هم نشده**؛ فقط بررسی ساختاری شده است. ممکن است در اولین Build چند خطای کامپایل کوچک ظاهر شود. متن خطا را برای من بفرستید تا رفع کنم.
- روی گوشی POCO واقعی تست نشده است؛ هر رفتار MIUI-محور (مثلاً حرکات ناوبری) فقط پیش‌بینی است.

## ۱. مشخصات دستگاه (باید روی گوشی خودتان تأیید شود)
مقادیر زیر از حافظه من است و **قطعی نیست**. مرجع واقعی، صفحه‌ی `Settings ← Device diagnostics` داخل خود برنامه است:
- POCO X3 GT 5G، کدنام معمولاً `chopin`، تراشه Dimensity 1100 (معماری `arm64-v8a`)، صفحه حدود 1080×2400 با 120Hz.
- نسخه اندروید زیر MIUI 14 را حدس نمی‌زنم؛ برنامه آن را نمایش می‌دهد. به همین دلیل `minSdk = 26` (اندروید 8 به بالا) انتخاب شده تا با هر نسخه سازگار باشد، و `targetSdk = 34`.

## ۲. ساخت APK
### روش الف) Android Studio
1. Android Studio (نسخه Koala/2024.1 یا جدیدتر) را باز کنید ← `Open` ← پوشه `GlassHome`.
2. صبر کنید Gradle Sync تمام شود (نیاز به اینترنت برای دانلود وابستگی‌ها).
3. منوی `Build ← Build Bundle(s)/APK(s) ← Build APK(s)`.
4. خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### روش ب) خط فرمان
```
gradle wrapper --gradle-version 8.7      # یک‌بار، برای ساخت gradlew
./gradlew assembleDebug
```
(JDK 17 و Android SDK 34 لازم است.)

### روش ج) بدون نصب چیزی روی PC: GitHub Actions
پروژه را در یک مخزن GitHub آپلود کنید؛ فایل `.github/workflows/build.yml` به‌صورت خودکار APK می‌سازد (بخش Actions ← Artifacts).

### APK نهایی (Release)
1. کلید بسازید: `keytool -genkey -v -keystore glass.jks -keyalg RSA -keysize 2048 -validity 10000 -alias glass`
2. فایل `keystore.properties` را کنار `build.gradle.kts` اصلی بسازید:
```
storeFile=../glass.jks
storePassword=****
keyAlias=glass
keyPassword=****
```
3. `./gradlew assembleRelease` ← خروجی: `app/build/outputs/apk/release/app-release.apk`
(بدون keystore، فایل release امضا نمی‌شود و نصب نخواهد شد. از debug استفاده کنید.)

## ۳. نصب روی POCO X3 GT (MIUI 14)
1. فایل APK را به گوشی منتقل کنید و باز کنید. اگر پرسید، «نصب از این منبع» را برای همان برنامه (Files/Chrome) مجاز کنید. در MIUI ممکن است «Install via USB / Security scan» هم پرسیده شود.
2. برنامه **«Glass Home»** نصب می‌شود. لانچر MIUI حذف یا تغییر نمی‌کند.

## ۴. تنظیم به‌عنوان لانچر پیش‌فرض
1. دکمه Home را بزنید ← پنجره انتخاب لانچر ← «Glass Home» ← «همیشه». یا:
2. تنظیمات ← برنامه‌ها ← مدیریت برنامه‌ها ← برنامه‌های پیش‌فرض ← لانچر ← Glass Home.
3. توصیه برای MIUI: تنظیمات ← برنامه‌ها ← مدیریت برنامه‌ها ← Glass Home ← «Autostart» روشن و «Battery saver» روی «No restrictions» تا MIUI برنامه را نبندد.
4. **احتمال مشکل (تست نشده):** در MIUI ممکن است حرکات تمام‌صفحه (Gestures) با لانچر غیر از لانچر سیستم انیمیشن/Recents کامل نداشته باشند. اگر دیدید، در تنظیمات ← صفحه نمایش ← ناوبری، «دکمه‌ها» را انتخاب کنید.

## ۵. بازگشت به لانچر اصلی MIUI / POCO ⭐
**دکمه داخل برنامه:** `Settings` (بالای صفحه) ← «Return to MIUI / Restore Original Home»، یا Control Center ← آیکن «MIUI Home»، یا لمس طولانی روی فضای خالی Home. (این صفحه فارسی است و پس از هر کرش، خودکار اول نمایش داده می‌شود.)

**بدون نیاز به برنامه (اگر خراب شد):**
1. تنظیمات ← برنامه‌ها ← مدیریت برنامه‌ها ← برنامه‌های پیش‌فرض ← لانچر ← **System launcher / POCO Launcher**.
2. اگر Home دوباره Glass Home را باز کرد: تنظیمات ← برنامه‌ها ← مدیریت برنامه‌ها ← Glass Home ← تنظیم به‌عنوان پیش‌فرض ← **Clear defaults**؛ سپس Home بزنید و لانچر اصلی را «همیشه» انتخاب کنید.
3. اگر به تنظیمات دسترسی ندارید: Safe Mode (در MIUI معمولاً: خاموش، روشن و نگه‌داشتن کلید کاهش صدا هنگام لوگو؛ روش دقیق ممکن است فرق کند) ← از آنجا Glass Home را Uninstall کنید.
4. با ADB: `adb uninstall com.glasshome.launcher` (فقط همین برنامه حذف می‌شود).

**محدودیت:** این فقط «برنامه Home» را عوض می‌کند، نه کل سیستم. اگر گوشی بوت نمی‌شود یا رام خراب است، هیچ دکمه‌ای در لانچر نمی‌تواند کمک کند؛ باید از ریکاوری رسمی Xiaomi استفاده کنید.
برنامه به هیچ پارتیشن سیستمی دست نمی‌زند، بوت‌لودر/روت لازم ندارد و لانچر اصلی را حذف نمی‌کند.

## ۶. مجوزها و دلیل هرکدام
| مجوز | دلیل | چگونه |
|---|---|---|
| `ACCESS_WIFI_STATE` | نمایش روشن/خاموش بودن Wi-Fi در Control Center | معمولی، خودکار |
| `WRITE_SETTINGS` (اختیاری) | کنترل مستقیم روشنایی و چرخش خودکار | فقط با اجازه شما در صفحه سیستم |
| Notification access (اختیاری) | نمایش اعلان‌ها در پنل شیشه‌ای | فقط با اجازه صریح؛ متن اعلان فقط در RAM، هرگز ذخیره/ارسال نمی‌شود |
| دسترسی به لیست برنامه‌ها | با `<queries>` (فقط برنامه‌های دارای آیکن لانچر) | بدون QUERY_ALL_PACKAGES |
| ❌ ندارد | اینترنت، موقعیت، مخاطبین، حافظه، دوربین، میکروفون | چراغ‌قوه و انتخاب عکس بدون مجوز انجام می‌شود |

## ۷. وضعیت ویژگی‌ها
### ✅ پیاده‌سازی‌شده (واقعی)
- لانچر: چند صفحه Home، Dock شناور، برنامه‌های واقعی نصب‌شده با نام و آیکن واقعی، پوشه، ذخیره چیدمان، باز کردن برنامه‌ها.
- جابه‌جایی با Drag (لمس طولانی و کشیدن): تغییر ترتیب در همان صفحه، رها کردن روی برنامه دیگر = ساخت پوشه، رها کردن روی Dock.
- منوی لمس طولانی: Open، میانبرهای برنامه (فقط وقتی لانچر پیش‌فرض است)، افزودن/حذف از Dock، انتقال به صفحه بعد، حذف از Home، App Info، Uninstall (با تأیید خود سیستم).
- App Library با دسته‌بندی، جست‌وجو، Recents (از لانچ‌های همین برنامه). Favorites = Dock.
- ویجت ساعت/تاریخ و باتری.
- Control Center (کشیدن از بالا-راست) با: چراغ‌قوه (مستقیم)، صدا (مستقیم)، روشنایی و چرخش (مستقیم با مجوز WRITE_SETTINGS)، نمایش وضعیت Wi-Fi/Bluetooth/Airplane/DND/باتری.
- پنل اعلان (کشیدن از بالا-چپ) با کارت‌های شیشه‌ای، پس از مجوز صریح.
- تنظیمات: تم، شفافیت، اندازه و گردی آیکن، والپیپر، Dock، شدت انیمیشن، Reduced effects، مرور مجوزها، حریم خصوصی.
- والپیپرهای اورجینال (تولیدشده با کد) + انتخاب عکس شخصی.
- ثبت کرش محلی و نمایش صفحه Recovery در اجرای بعد؛ پس از ۲ کرش، جلوه‌ها خودکار سبک می‌شوند.
- صفحه Diagnostics (کدنام، نسخه اندروید، ABI، ابعاد، MIUI، لانچر پیش‌فرض).

### ↗ فقط باز می‌کند (اندروید اجازه تغییر مستقیم نمی‌دهد)
Wi-Fi، Bluetooth، Airplane، Internet، Do Not Disturb، Battery. در UI با علامت ↗ مشخص شده‌اند و هرگز وانمود نمی‌کنند که تغییر کرده‌اند.

### 🎨 شبیه‌سازی بصری
- **اثر شیشه:** نسخه از پیش‌محوشده‌ی والپیپر پشت سطوح شیشه‌ای کشیده می‌شود (ارزان و کم‌مصرف)، همراه با رنگ، براق‌سازی و حاشیه شیب‌دار. این «بلور زنده» محتوای پشت شیشه (مثلاً آیکن‌ها) و شکست نور (lensing) واقعی Liquid Glass نیست.
- **صفحه قفل:** فقط پیش‌نمایش بصری داخل لانچر است. قفل واقعی (PIN/اثرانگشت) دست‌نخورده است و این صفحه امنیتی نیست.

### ❌ پشتیبانی نمی‌شود / انجام نشده
- **تغییر ظاهر داخل برنامه‌های دیگر (مثل Instagram):** ممکن نیست. هر برنامه رابط خودش را رسم می‌کند و اندروید به لانچر اجازه نمی‌دهد آن را تغییر دهد. راه‌هایش (روت، LSPosed، ریپک برنامه) خارج از قوانین ایمنی این پروژه است.
- جایگزینی نوار وضعیت/سایه اعلان واقعی MIUI یا قفل‌صفحه واقعی.
- ویجت آب‌وهوا (نیاز به اینترنت و موقعیت دارد؛ عمداً حذف شد تا برنامه صفر مجوز شبکه داشته باشد).
- ویجت‌های برنامه‌های دیگر (AppWidgetHost)، کشیدن آیتم بین صفحه‌ها با لبه صفحه (به‌جایش «Move to Next Page»)، فونت SF Pro (متعلق به اپل)، آیکن‌پک سفارشی برای هر برنامه.
- هیچ‌چیز روی گوشی تست نشده است.
